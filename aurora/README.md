# Aurora Music 🎵

Красивый мобильный музыкальный плеер + загрузчик треков с YouTube в высоком качестве.
Одна кодовая база: работает на ПК, ставится на телефон как PWA, а также собирается в полноценное Android-приложение (APK) с **офлайн-прослушиванием**.

## Что умеет
- Скачивание треков с YouTube в **высоком качестве** (AAC до ~320 кбит/с) с обложками и метаданными.
- Поиск по названию **или** вставка прямой ссылки YouTube.
- **Офлайн**: кнопка «Скачать офлайн» у каждого трека — аудио + обложка сохраняются в память приложения и играют без сети и без ПК.
- Красивый плеер (тёмная тема, стекло): обложки, очередь, перемешивание, повтор, перемотка, громкость.
- **Громкость**: ползунок в полноэкранном режиме **и** кнопка-динамик с ползунком в мини-плеере.
- Управление с **экрана блокировки телефона** (MediaSession).

## Быстрый старт (на ПК)
1. Нужен Node.js 18+ (https://nodejs.org).
2. Запустите `start.cmd` двойным кликом — откроется браузер с плеером.
   Или в терминале: `node server.js`.
3. Нажмите **«+»**, вставьте ссылку YouTube или введите название → скачайте трек.

## Офлайн-прослушивание
- У каждого трека в списке есть кнопка **⭳ «Скачать офлайн»**. Нажмите — трек и обложка сохранятся в память приложения (значок станет ✓).
- Сохранённые треки играют **без интернета и без включённого ПК**.
- Повторное нажатие на ✓ удаляет офлайн-копию.
- Работает и в PWA, и в установленном APK.

## Установка на телефон (PWA, без сборки)
1. ПК и телефон — в **одной Wi-Fi сети**.
2. В консоли сервера показан адрес вида `Phone : http://192.168.x.x:8787/`. Откройте его в браузере телефона.
3. **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
   **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
4. Готово — иконка **Aurora** на главном экране, приложение на весь экран.

## Сборка полноценного Android-приложения (APK)
Нужны: Node.js 18+, **Android Studio** (Android SDK + JDK 17) на ПК.

```bash
cd aurora
npm install            # ставит Capacitor
npm run cap:add        # создаёт папку android/
npm run cap:open       # открывает Android Studio
```
В Android Studio: **Build → Build Bundle(s)/APK(s) → Build APK(s)**.
Или из терминала: `cd android && gradlew.bat assembleDebug`.

Готовый APK: `android/app/build/outputs/apk/debug/app-debug.apk` — перенесите на телефон и установите.

### Настройка APK (важно)
Внутри приложения откройте **Настройки** (шестерёнка) и укажите адрес ПК, например `http://192.168.0.101:8787` (адрес виден в консоли сервера). ПК и телефон должны быть в одной Wi-Fi сети. После этого приложение скачивает треки с ПК, а «Скачать офлайн» делает их доступными без сети.

> Если приложение не может связаться с сервером (Android блокирует незашифрованный HTTP): в `android/app/src/main/AndroidManifest.xml` добавьте в тег `<application>` атрибут `android:usesCleartextTraffic="true"` и пересоберите. (В подготовленном проекте этот флаг уже стоит.)

### Сборка APK без Android Studio (в облаке через GitHub)
В папке `aurora` уже лежит готовый рабочий процесс GitHub Actions — он соберёт APK на серверах GitHub, и Android Studio на вашем ПК **не нужен**:

1. Создайте бесплатный аккаунт на github.com и новый пустой репозиторий.
2. На ПК в папке `aurora` выполните:
   ```bash
   git init
   git add .
   git commit -m "Aurora"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/aurora.git
   git push -u origin main
   ```
3. На GitHub откройте вкладку **Actions** — автоматически запустится сборка `Build Aurora APK`.
4. Когда сборка закончится (зелёная галочка), зайдите в неё → **Artifacts** → скачайте `aurora-apk`.
5. Распакуйте и установите `app-debug.apk` на телефон (разрешив установку из неизвестных источников).

Внутри приложения в **Настройках** укажите адрес ПК: `http://<IP-ПК>:8787`.

## Структура проекта
```
aurora/
  server.js            — сервер (чистый Node.js, без npm-зависимостей)
  start.cmd            — запуск в один клик (Windows)
  capacitor.config.json— конфиг Capacitor для сборки APK
  public/              — плеер (HTML/CSS/JS + PWA + иконки)
    offline.js         — офлайн-хранилище (IndexedDB)
  library/             — скачанные треки и обложки
  library.json         — индекс треков (создаётся автоматически)
  bin/                 — yt-dlp.exe, ffmpeg.exe (запасной вариант без Python)
  pylibs/              — yt-dlp как Python-модуль
  scripts/             — вспомогательные скрипты загрузки инструментов
```

## Примечания
- **Скачивайте только тот контент, на который у вас есть права** (например, музыка Creative Commons или ваша собственная). Инструмент — для личного использования.
- yt-dlp иногда пишет предупреждение про JS-runtime (deno). На качестве аудио это не сказывается — берётся лучший аудиопоток.
- **Видео с возрастным ограничением** («Sign in to confirm your age»): есть два способа.
  1. **Файл `cookies.txt` (надёжнее):** поставьте расширение браузера «Get cookies.txt LOCALLY», откройте youtube.com, экспортируйте куки и сохраните файл как `aurora/cookies.txt`. Загрузчик будет использовать его автоматически.
  2. **Из браузера:** укажите в **Настройках** браузер, в котором вы залогинены в YouTube на этом ПК (например `chrome`). Работает при обычном запуске (`start.cmd`), но не в ограниченной песочнице.
- Порт по умолчанию `8787`. Изменить: `set PORT=9000 && node server.js`.
- Если на машине нет Python, загрузчик автоматически использует `bin/yt-dlp.exe`.
